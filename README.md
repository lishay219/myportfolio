## 📖 About The Project

This project represents my first experience working with Figma and converting a UI design into a fully functional website.

The goal was to improve my understanding of:

- UI Design Implementation
- HTML Structure
- CSS Layout Techniques
- Responsive Design
- Multi-page Website Development
